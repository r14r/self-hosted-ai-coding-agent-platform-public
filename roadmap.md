# Implementierungsplan

| Zeitraum | Schwerpunkte |
|---|---|
| Woche 1–2 | Compose Foundation, FastAPI, UI, Datenbanken, Ollama |
| Woche 3–4 | Git Provider, Repository Discovery, Maintenance Tasks |
| Woche 5–6 | OpenCode, Modelladapter, isolierter Executor |
| Woche 7–8 | Baseline, Build/Test, Security-Validierung |
| Woche 9–10 | Diff Review, Pull Requests, menschliche Freigabe |
| Woche 11–12 | Hardening, Evaluationen, Audit und Demo |

3 Tage pro Woche; ungefähr 30–36 Entwicklungstage.

## MVP

Ein Repository wird analysiert, die Wartungsaufgabe in einer Sandbox ausgeführt, unabhängig validiert und als Pull Request zur Prüfung erstellt. Der Agent hat niemals die Berechtigung, geschützte Branches selbst zu mergen.

**Aktuell vorhanden:** Compose, FastAPI-Grundgerüst, optionale Gitea-/Ollama-Dienste, statische Landing Page und CI. Die nachfolgenden Funktionalitäten sind noch nicht implementiert.
