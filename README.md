# Self-Hosted AI Coding Agent Platform — Public Jekyll Website

Public documentation website for the private implementation project [self-hosted-ai-coding-agent-platform](https://github.com/r14r/self-hosted-ai-coding-agent-platform).

Published URL: https://r14r.github.io/self-hosted-ai-coding-agent-platform-public/

## Deployment

GitHub Actions deploys this root-level Jekyll project to GitHub Pages on each push to main. Enable **Settings → Pages → Build and deployment → GitHub Actions**.

## Local preview

```bash
bundle install
bundle exec jekyll serve
```

Open http://127.0.0.1:4000/self-hosted-ai-coding-agent-platform-public/

The private implementation repository is not included here; only publicly intended content and diagrams are published.
